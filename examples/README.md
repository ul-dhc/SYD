# Example projects

This directory will contain demonstration datasets and SYD project configurations.

The first planned examples are:

1. **NSRD/Seque** — the existing recordings, people, formats, groups, and institutions explorer;
2. **A second humanities dataset** — structurally different from NSRD and used to verify that a new project requires configuration rather than changes to the SYD core.

No research dataset should be added here until its publication rights and intended level of access have been confirmed.
