# Example projects

This directory contains demonstration datasets and will later contain SYD project configurations.

The first planned examples are:

1. **Cultural events** — a small synthetic CSV used by the first browser workflow;
2. **NSRD/Seque** — the existing recordings, people, formats, groups, and institutions explorer;
3. **A second humanities dataset** — structurally different from NSRD and used to verify that a new project requires configuration rather than changes to the SYD core.

No real research dataset should be added here until its publication rights and intended level of access have been confirmed.
